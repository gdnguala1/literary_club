Literary Club

# Описание проекта

Literary Club — учебный проект, созданный в рамках лабораторной работы № 2 «Документирование программных проектов: GitHub, Markdown и PlantUML».

Цель работы — изучить основы системы контроля версий Git, научиться работать с платформой GitHub, оформлять документацию с помощью Markdown и создавать диаграммы с использованием PlantUML.

В текущей версии программа на Python выводит сообщение Hello, World!. Диаграмма вариантов использования описывает предполагаемые функции литературного клуба.

# Используемые технологии

Технология|Назначение
Python	Разработка и запуск программы

PlantUML	Создание UML-диаграмм
Visual Studio Code	Редактирование кода и документации

# Запуск программы

Требования

Для запуска программы необходимо установить Python.

Инструкция по запуску

1. Открыть папку проекта в Visual Studio Code.
2. Открыть терминал.
3. Выполнить команду:

python main.py

Ожидаемый результат:

Hello, World!

# Диаграмма вариантов использования

Диаграмма описывает взаимодействие пользователей с системой Literary Club.

Основные акторы:

* Посетитель — просматривает каталог книг, ищет книги, изучает информацию о книгах и может создать аккаунт.
* Участник — входит в систему, присоединяется к книжным клубам и участвует в обсуждениях.
* Администратор — управляет книгами, клубами, мероприятиями и участниками.

Представленные на диаграмме функции описывают предполагаемые возможности системы и не обязательно реализованы в текущей версии программы.

# Цели лабораторной работы

В ходе выполнения лабораторной работы были рассмотрены следующие задачи:

1. Настройка среды разработки и системы контроля версий Git.
2. Создание локального и удалённого репозитория.
3. Выполнение операций commit, pull и push.
4. Создание документации с использованием Markdown.
5. Разработка диаграммы вариантов использования с помощью PlantUML.
6. Публикация проекта на GitHub.

8. Заключение

В результате выполнения лабораторной работы были изучены основные принципы работы с Git и GitHub, освоены базовые элементы Markdown и получены практические навыки создания UML-диаграмм с помощью PlantUML.
